Overview

PlantVillage Dataset

The Plant Disease Recognition System is trained on the renowned PlantVillage Dataset, which is an open-access, comprehensive dataset created by Penn State University. It is one of the most widely used datasets for machine learning research in plant pathology.

This dataset contains a vast collection of healthy and diseased crop leaf images, carefully labeled across 38 different disease categories covering 14 different crop types. The images were captured under controlled conditions to ensure high quality and consistency for training deep learning models.

By using this dataset, our model learns the subtle visual differences between various diseases, such as leaf spots, blights, rusts, and molds, enabling it to provide highly accurate diagnoses.

Technology

Model Architecture

Built with modern deep learning frameworks

CNN Architecture

Utilizes Convolutional Neural Networks (CNNs) which are highly effective for image processing tasks. The network consists of multiple convolutional layers, max-pooling layers, and dense layers to extract complex features.

TensorFlow & Keras

The model is implemented using TensorFlow 2.x and the Keras API. This ensures high performance, easy deployment, and the ability to leverage GPU acceleration for faster training and inference.

Image Preprocessing

Input images are resized to 128x128 pixels and normalized. Data augmentation techniques like rotation, zoom, and horizontal flipping were used during training to make the model robust.

High Accuracy

The model underwent rigorous training for multiple epochs, achieving over 99% accuracy on the validation set, ensuring reliable predictions when deployed in real-world scenarios.
